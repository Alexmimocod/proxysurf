ProxySurf

Браузер для серфинга через ваш socks5-прокси.
Вставили прокси — поехали.

СКАЧАТЬ ProxySurf.apk

Установка:

  1. Откройте скачанный файл
  2. Разрешите установку из этого источника (одноразово)
  3. В приложении: «ПРОКСИ» → вставьте строку вида
    socks5://user:pass@ip:port → «Применить»
