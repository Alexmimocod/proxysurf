Установка:

  1. Откройте скачанный файл
  2. Разрешите установку из этого источника (одноразово)
  3. В приложении: 🌐 → вставьте строку вида
    socks5://user:pass@ip:port → «Применить»
  4. Проверка версии: в строке статуса под панелью написано «ProxySurf v1.4»
